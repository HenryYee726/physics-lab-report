# 大学物理实验报告

从当前工作区读取材料，完成适合本科生课程的实验报告。此 skill 保存工作流程，不内置某一本教材、某次实验数据或固定报告模板。用户当次的明确要求优先。

## 工作区与文件识别

默认结构如下；识别实际文件名，不要求用户重命名或移动已有文件。

```text
工作区/
├─ 参考教材.pdf
├─ template/
│  ├─ Writing a lab report-Appendix 1.pdf
│  ├─ Template for long report.docx
│  └─ Template for short report.docx
└─ lab/
   └─ labX/
      ├─ 原始数据.jpg                 # 可有多张照片，或扫描 PDF
      ├─ 数据表格.docx
      ├─ prelab.docx                 # 可选
      └─ 姓名+学号+实验名称+postlab.docx # 最终输出
```

- 容许 `Lab`/`lab`、文件名前缀编号、年份、中英文名称等差异。按文件用途和内容匹配。
- 先确定用户指定的实验和 `labX`。目录编号、教材章节编号、课件编号可能不同，以完整实验名称核对。
- 长短报告由用户指示或已明确的任务上下文决定。若两种模板均存在且无法确定，简短询问，同时继续读取写作要求等独立工作；不要自行把长报告设为永久默认。
- 若多个文件都可能是所需模板、教材或原始记录，先核对内容；确有歧义再询问。不要把以前生成的 postlab 当作原始数据。
- 本次实验的表格优先取自 `labX`。若缺失，检查 `template` 中是否有明确对应实验的汇总表格；仍无可用表格时向用户说明并索取，不自行重建或从别的实验套用。

## 读取与写作顺序

### 1. 先读课程写作要求，再读选定模板

首先完整读取 `Writing a lab report-Appendix 1`，确认各部分应包含的内容。再读取长报告或短报告模板，确认章节顺序、评分栏、字数要求和附录安排。

写作要求规定各部分的内容，所选模板规定实际需要哪些部分及其布局。短报告按短模板完成，不额外塞入长报告的全部章节。有无法合理协调的实质冲突时，在聊天中说明并询问。

创建或编辑 Word、读取 PDF 和检查版式时，使用当前可用的 Documents、PDF 技能。运行环境通过 workspace dependency loader 获取，不硬编码旧版插件或依赖路径。

### 2. 读取本次原始材料

查看手写记录的完整页面及对应 Word 表格，核对表头、单位、读数、常量和实验条件。需要时放大局部检查，但保留完整记录。

- 原始测量值以手写记录为依据；表格文件规定布局与栏目。若电子表格已有数值且与手写记录不同，核对来源，无法判定时询问。
- 可从 prelab 核对姓名、学号、教师和实验名称。预习报告日期不自动视为实验日期。
- 读不清的数据不猜测；缺失的测量值、仪器精度、日期和实验现象不编造。必要问题在聊天中提出，其他不依赖该问题的工作继续进行。
- 保留原始材料，不用处理后的结果覆盖原始读数。

### 3. 通过目录定位教材章节

先读取教材目录，按实验名称找到起始页及下一章位置。检查印刷页码与 PDF 页序之间的偏移，再读取该实验的完整相关章节，包括原理、步骤、数据处理及 postlab questions。

**禁止为了找章节而全文提取、全文 OCR 或逐页渲染整本教材。** 扫描教材仅渲染目录和目标章节；只有目标章节明确引用且当前任务确实需要时，才另行读取被引用的页段。当前会话已有可靠定位记录时可复用，材料变更后重新核对。

### 4. 完成数据处理与正文，最后写 Abstract

按该实验章节规定的方法、单位、参考值和不确定度要求计算，不把某次实验的方法或常量固定用于其他实验。复核单位换算、平均值、有效数字及百分误差。

- 不为贴近理论值修改原始数据。手写的派生计算若有算术错误，使用核对后的结果，并在聊天中说明差异。
- 只计算教材或课程要求的不确定度及比较指标。不要为了显得严谨而添加无关统计分析、检验或多套误差指标。
- 中间计算保留足够精度，最终结果合理舍入。不能凭小数位数臆造仪器精度，也不能因重复读数相同就认定没有误差。
- 正文完成后再写摘要，确保目的、主要结果和结论与正文一致。
- 回答本章全部 postlab questions，不把 prelab questions 无差别重复加入。
- References 仅列实际使用的教材和相关材料，采用课程要求的引用格式，不编造文献或出版信息。

## 报告语气与聊天备注

默认使用模板和课程材料的语言；英文模板配英文教材时写英文报告。与用户沟通沿用用户语言。

采用自然、直接的本科生实验报告语气：说明做了什么、如何计算、得到什么结果及主要误差来源。保持物理和计算正确，避免论文式铺陈、过度限定、泛泛赞美实验意义和重复总结。字数满足模板要求，不刻意堆长。

Discussion 按课程要求比较理论与实验，并解释具体的仪器或操作机制。不要仅用笼统的 “human error” 敷衍，也不要把推测的误差来源写成确实发生的事件。

区分两类内容：

- **报告内容：** 正常实验原理、步骤、数据表、计算、必要的物理假设、结果、具体误差分析及题目答案。
- **聊天备注：** 文件如何读取或拼接、使用哪份模板、材料缺失、读数歧义、教材疑似笔误、日期待确认、数据修正说明及其他需要用户注意的事项。

聊天备注不得混入报告。不要出现“根据用户提供的文件”“原图保存在某路径”“未能找到仪器规格”“为了保留模板所以……”等制作过程说明。必要的科学定义仍应写清；若资料问题妨碍得到可靠结果，先在聊天中解决，不隐瞒或编造完整结论。

## 在模板上制作文档

### 模板与水印

从选定模板的副本编辑，不从空白文档重建。保留水印、背景图片、校徽、页眉页脚、评分栏、页面尺寸、页边距及原有样式。替换或填写内容，并按篇幅合理分页；避免无意义空白页和孤立标题。

修改现有报告时检查用户已经做过的修改，保留与当前任务无关的编辑。不得直接重跑旧生成脚本覆盖用户改动。

### 数据表格

直接复制用户提供的对应 Word 表格，保留表头、行列结构、合并单元格、边框、单位、公式、列宽和标题，只填写所需内容。不要重画相似表格，不转成截图代替可编辑表格。复制时保全表格依赖的样式、公式及关系，避免目标文档样式冲突改变外观。

表格放入所选模板的 Results 或 Calculations and Results 等对应位置。计算过程按模板安排；不要重复堆放同一组结果。

### 手写数据附录

将本次手写原始记录**实际插入 Appendix 的 Scanned data sheets 部分**。这不是仅写文件名或路径的占位说明。多张照片或扫描 PDF 按记录顺序插入，完整保留读数、单位、批注及签名；等比例缩放，必要时分多页以保证可读性。

保留模板水印。不要为了贴图而遮掉整页背景，或改写原始记录。若用户当次明确要求不嵌入图片，则按该要求处理，并在聊天中说明附录状态。

### 公式

公式必须经过 LaTeX 排版转换并在最终文档中正确渲染，不交付原始美元符号、反斜杠命令或普通文本堆砌的分式。优先使用可编辑的 Word 原生公式；可将 LaTeX 转为 MathML，再转换为 OMML。若采用其他渲染方式，同样检查清晰度、基线及缩放。

检查分式、根号、求和、上下标、均值横线、希腊字母、正负号及单位间距。不能仅以 XML 中存在公式节点作为显示正确的证据。

## 验证与交付

核对原始数据转录、全部指定计算、题目答案及报告各节内容；确认摘要和结论使用同一组最终结果。

将最终 DOCX 渲染为逐页预览，逐页检查水印、数据表、公式、页码、分页及原始记录图片是否完整清楚；修复缺字、裁切、重叠、溢出和多余空白页。检查复制表格的视觉格式与源表一致，以及模板原有背景和页眉页脚未被意外改变。若渲染确实不可用，在聊天中如实说明，不能声称已通过视觉检查。

默认把最终 DOCX 保存至对应 `labX`，文件名采用用户指定方式，否则使用 `姓名+学号+实验名称+postlab.docx`。生成辅助文件集中放在工作区临时目录，不混入最终交付；仅在用户要求时另交 PDF。已有同名报告时按任务语义处理，避免覆盖无关或无法确认归属的文件。

最终在聊天中提供报告链接，并简短列出仍需用户确认的事项。原始教材、模板、数据表文件和手写记录保持不变。

# Physics lab report workspace

When asked to generate or revise a physics postlab report, read and follow `.agents/skills/physics-lab-report/SKILL.md`.

- Use the materials in this repository and the user's selected `lab/labX/` folder. Do not start generating reports merely because the repository was opened.
- Read `template/Writing a lab report-Appendix 1.pdf` first. Choose the long or short template according to the user's request.
- Read the reference textbook's contents first, then only the relevant experiment chapter. Do not extract or OCR the whole book.
- Preserve template watermarks, copy the supplied Word data tables, insert the actual handwritten records into the appendix, and render the equations and final document.
- Keep private input data and generated reports local. Publishing the reusable project does not authorize publishing a user's later experiments.
- Put working files in `tmp/`; save the final report in the selected experiment folder. Do not overwrite original materials.
